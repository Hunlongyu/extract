## English

First packaged release of Extract for Windows 10 / 11.

- Drag one or more installers onto the EXE to extract files without running the installer, then open the results through a system notification.
- Supports tested Inno Setup, NSIS, MSI, WiX Burn, CAB, ZIP / ZIP64, 7z, and self-extracting layouts. Customized packages may be unsupported.
- Automatically extracts recognized nested installers, including selected Electron / Tauri packages, and preserves existing output folders.
- Handles MSI packages with embedded or external CABs and loose files, plus locally available Burn payloads. Missing payloads produce a partial result.
- Removes fixed package-size, output-size, and file-count limits. Actual disk space, memory, and format limits still apply.
- Records extraction steps and failure details with automatic log cleanup and an AppData fallback when the program directory is not writable.
- Provides standalone x86, x64, and ARM64 executables with no VC++ runtime installation required, plus checksums and third-party notices.
- Includes a simplified bilingual README with badges, quick navigation, usage instructions, and supported formats.

Choose x64 for Intel / AMD 64-bit Windows, ARM64 for ARM Windows, or x86 for 32-bit Windows. ARM64 is cross-compiled; runtime testing on ARM64 hardware is pending. Extracted applications may still require installation.

## 简体中文

Extract 首个打包发布版本，适用于 Windows 10 / 11。

- 将一个或多个安装包拖到 EXE 上即可提取文件，不运行安装程序，通过系统通知打开结果。
- 支持已验证的 Inno Setup、NSIS、MSI、WiX Burn、CAB、ZIP / ZIP64、7z 及自解压结构，定制封装可能不受支持。
- 自动提取可识别的内层安装包，覆盖部分 Electron / Tauri 封装，并保留已有输出目录。
- 支持 MSI 的内嵌或外置 CAB、松散文件及 Burn 的本地载荷，缺失载荷时提示部分完成。
- 取消统一的安装包大小、输出总量和文件数量限制，仍受实际磁盘空间、内存及格式限制。
- 记录解包步骤和失败原因，自动清理日志；程序目录不可写时回退到 AppData。
- 提供 x86、x64、ARM64 独立 EXE，无需安装 VC++ 运行库，附带校验和与第三方许可。
- 精简中英文 README，增加徽章、快速导航、使用说明和支持格式介绍。

Intel / AMD 64 位 Windows 选择 x64，ARM Windows 选择 ARM64，32 位 Windows 选择 x86。ARM64 为交叉编译产物，实机运行验证待完成。提取出的应用仍可能需要安装。
