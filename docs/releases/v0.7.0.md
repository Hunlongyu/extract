## English

- Adds support for more standard Inno Setup 6.0, 6.3, 6.4, and 6.6 layouts, with clearer errors for unsupported volume parameters or modified headers.
- Adds support for selected NSIS 2.x ANSI layouts, including Chinese filenames; resolves extraction failure for the tested QQMusic package.
- Separates recognized NSIS architecture branches into `app-x86`, `app-x64`, or `app-arm64`, keeping their shared resources together and fixing scattered files in the tested Beyond Compare package.
- Adds live system-notification progress with the current package, processing stage, byte counts, and elapsed time. File verification no longer replaces cumulative extraction progress with a per-file percentage; preparation and nested packages show their own activity.
- Keeps the final result in the same notification, with the package name, output folder or failure reason. Adds **Open folder** / **View results** buttons and removes repeated completion labels and extra completion popups. Button labels currently appear in Chinese.
- Adds developer information to executable properties and improves bilingual README formatting, usage instructions, and compatibility documentation.

Download the standalone EXE for x86, x64, or ARM64 Windows 10 / 11. No VC++ runtime installation is required. ARM64 runtime testing on hardware is pending.

Compatibility remains layout-specific: modified or encrypted Inno repacks and NSIS 3.x ANSI layouts are not covered by these additions.

## 简体中文

- 扩展 Inno Setup 6.0、6.3、6.4、6.6 的标准布局支持，明确提示不受支持的分卷参数或修改版头部。
- 支持部分 NSIS 2.x ANSI 布局及中文文件名，修复已测试 QQMusic 安装包的解包失败。
- 将已识别的 NSIS 架构分支分别整理到 `app-x86`、`app-x64` 或 `app-arm64`，保留所需公共资源，修复已测试 Beyond Compare 安装包的文件散落问题。
- 增加系统通知实时进度，显示当前包、处理阶段、字节数和耗时。文件校验不再用单文件百分比覆盖累计提取进度，准备阶段和内层包分别显示处理状态。
- 在同一条通知中显示最终结果、包名、输出目录或失败原因，增加 **打开文件夹**／**查看结果** 按钮，去除重复的完成文案和额外完成弹窗。
- 在程序属性中补充开发者信息，优化双语 README 的排版、使用说明和兼容性文档。

提供适用于 Windows 10 / 11 的 x86、x64、ARM64 独立 EXE，无需安装 VC++ 运行库。ARM64 实机运行验证待完成。

兼容性仍取决于具体布局：本次扩展不包含修改版或加密的 Inno 重打包，也不包含 NSIS 3.x ANSI 布局。
