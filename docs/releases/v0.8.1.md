## English

- Adds extraction for tested Velopack and Squirrel.Windows offline installers and full update packages, collecting application files under `app` and keeping separate targets in separate folders.
- Adds unencrypted MSIX, APPX, and Bundle extraction with block hash verification. Embedded architectures and resource packages are extracted separately; missing external members produce a partial result.
- Adds Inno Setup external `.bin` volumes, including files and solid compressed blocks spanning multiple volumes. Missing, mismatched, or damaged volumes now report explicit errors.
- Adds standard CAB spanning sets: extraction can start from the first, middle, or last volume. MSI also supports embedded, external, and mixed CAB chains while preserving its file directories.
- Adds **Cancel task** to progress notifications, plus `--cancel` and `--cancel-last`. Cancellation stops the current package and the rest of its batch while keeping already completed output. Notification buttons currently appear in Chinese.
- Adds optional per-package timeouts through `--timeout <seconds>`, disabled by default. A timed-out or crashed package is recorded and the batch continues with the next input.
- Isolates extraction in a worker process and improves temporary-file cleanup after worker failures. Interrupted task records are identified when revisited; completed output is preserved.

Keep all split volumes together with their original filenames. Drop the Inno EXE, MSI, or any CAB volume onto Extract.

Download the standalone EXE for x86, x64, or ARM64 Windows 10 / 11. No VC++ runtime installation or external extraction tool is required. ARM64 runtime testing on hardware is pending.

Support remains specific to tested layouts. Modified or encrypted Inno packages, Burn-internal spanning CABs, split ZIP/7z archives, and delta update reconstruction remain unsupported. Extracted MSIX/APPX applications may still need installation to run.

## 简体中文

- 支持已验证的 Velopack、Squirrel.Windows 离线安装包和完整更新包，将应用文件集中到 `app`，不同目标分别保留目录。
- 支持未加密 MSIX、APPX 和 Bundle 解包及块哈希校验，内嵌架构和资源包分目录展开；缺少外置成员时提示部分完成。
- 支持 Inno Setup 外置 `.bin` 分卷，可还原跨卷文件及固实压缩块；缺卷、错卷和损坏分卷会明确报错。
- 支持标准 CAB 跨卷续接，可从首卷、中间卷或末卷开始提取；MSI 同时支持内嵌、外置和混合 CAB 卷链，并保留文件目录结构。
- 进度通知增加 **取消任务**，同时提供 `--cancel` 和 `--cancel-last` 命令。取消会停止当前包及批次中剩余的包，保留已完成的输出。
- 增加 `--timeout <秒>` 单包超时设置，默认关闭。单包超时或崩溃会记录原因，并继续处理批次中的下一个输入。
- 使用独立工作进程解包，完善工作进程异常后的临时文件清理；再次查看任务时识别中断记录，保留已完成的输出。

分卷请保留原始文件名并放在同一目录，拖入 Inno 的 EXE、MSI 或任意 CAB 卷即可。

提供适用于 Windows 10 / 11 的 x86、x64、ARM64 独立 EXE，无需安装 VC++ 运行库或额外解包工具。ARM64 实机运行验证待完成。

支持范围以已验证布局为准。修改版或加密 Inno、Burn 内部跨卷 CAB、分卷 ZIP/7z 和差分更新还原仍不支持。MSIX/APPX 应用解包后仍可能需要安装才能运行。
