## English

- Adds compact output folders: a clearly identified application moves to the result root, additional files go under `_extra`, and multiple applications or architectures stay separate. Nested packages and their contents are retained; ambiguous layouts keep their relative structure.
- Improves NSIS user and system directory handling. Logical paths and wrapper launch, wait, and cleanup operations are recorded without executing them or writing to actual system locations.
- Preserves NSIS compiled instructions, operands, raw strings, and decompressed metadata in `_extract-script`. Nested scripts and reports are grouped under `_extract-packages`; these records are not recovered original `.nsi` source.
- Adds a combined extraction report with final paths and original-path mappings, plus size and SHA-256 verification when organizing files. Improves temporary-file cleanup during cancellation and worker termination.
- Refreshes the bilingual README with architecture-specific downloads, a total download badge, and easier-to-scan usage instructions.

**Upgrade notes:** Compact layout is now the default. Use `--layout original` to keep the previous folder layout and per-package reports. Compact reports use `pathBase: extraction-root`, with file paths relative to the final result root; update report consumers accordingly. Compact layout temporarily needs space for both decoded files and the final copy. Standalone ZIP / 7z and MSIX / APPX retain their package hierarchy.

## 简体中文

- 新增精简输出目录：明确识别的应用提升到结果根目录，附加文件归入 `_extra`，多个应用或架构分别保存。内层包及其内容保留，存在歧义时保持相对结构。
- 改进 NSIS 用户目录和系统目录的解析，记录逻辑路径及外壳启动、等待、清理行为，不执行这些操作，也不写入真实系统目录。
- 在 `_extract-script` 保留 NSIS 编译指令、参数、原始字符串与解压后的元数据；内层脚本和报告集中到 `_extract-packages`。这些记录不是恢复出的原始 `.nsi` 源码。
- 增加汇总提取报告，记录最终路径与原路径映射；整理文件时校验大小和 SHA-256，并改进取消任务和工作进程终止时的临时文件清理。
- 优化双语 README，增加三架构下载入口、累计下载次数徽章及更便于查阅的使用说明。

**升级提示：**默认输出改为精简布局。使用 `--layout original` 可保留旧目录层级和逐包报告。精简报告使用 `pathBase: extraction-root`，文件路径相对最终结果根目录；读取报告的工具需相应调整。整理期间需要同时容纳解码后的文件与最终副本。独立 ZIP / 7z 和 MSIX / APPX 保持包内层级。
