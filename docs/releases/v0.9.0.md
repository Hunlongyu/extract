## English

- **Compact folders:** Bring identified apps to the output root; keep extras and different apps or architectures separate. Preserve nested packages and ambiguous folder structures.
- **NSIS paths:** Improve user/system directory handling and record launch, wait, and cleanup actions without executing them.
- **NSIS records:** Preserve compiled instructions and metadata; group nested scripts and reports for easier inspection.
- **Reports and cleanup:** Map original paths to saved files, verify copied files, and improve cleanup after cancellation or worker termination.
- **README:** Add clearer bilingual instructions, architecture-specific downloads, and a cumulative download badge.

**Upgrade notes**

- Compact layout is now the default. Use `--layout original` to retain the previous folders and per-package reports. Standalone ZIP / 7z and MSIX / APPX keep their hierarchy.
- Compact layout temporarily needs space for two copies. Report paths are relative to the final output root (`pathBase: extraction-root`); adjust report-reading tools accordingly.

## 简体中文

- **精简目录**：应用文件更易查找，附加文件、多应用和不同架构分别保存；保留内层包及有歧义的目录结构。
- **NSIS 路径**：改进用户与系统目录解析，静态记录启动、等待和清理行为，不执行包内命令。
- **NSIS 记录**：保留编译指令与元数据，集中保存内层脚本和报告，便于查阅。
- **报告与清理**：记录原路径与保存位置，校验复制后的文件，改进取消任务和进程终止后的临时文件清理。
- **使用文档**：优化双语说明，增加三架构下载入口和累计下载次数徽章。

**升级提示**

- 默认使用精简布局；添加 `--layout original` 可保留旧目录层级和逐包报告。独立 ZIP / 7z 和 MSIX / APPX 保持包内层级。
- 精简整理期间需要两份文件的磁盘空间。报告路径相对最终结果根目录（`pathBase: extraction-root`），读取报告的工具需相应调整。
